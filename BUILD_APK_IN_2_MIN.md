
# HOW TO GET APK IN 2 MINUTES - NO ANDROID STUDIO NEEDED

## METHOD 1: GitHub Auto Build (EASIEST - 2 min)
1. Go to https://github.com -> Create new repository named "bsnl-noc-parser"
2. Upload all files from this zip (drag & drop)
3. Click "Actions" tab -> You will see "Build BSNL NOC APK" running
4. After 2-3 min, click on build -> Download artifact "BSNL-NOC-Parser-APK"
5. You get app-debug.apk -> Install on phone

## METHOD 2: Android Studio (If you have PC)
1. Download Android Studio from developer.android.com
2. Open this folder
3. Click Build -> Build APK -> app-debug.apk in app/build/outputs/apk/debug/

## METHOD 3: I build for you - Use this online builder
Go to https://www.apkonline.net/ or https://appetize.io/

## AFTER INSTALL:
1. Install APK on phone
2. Open App -> Allow SMS permission (Very Important)
3. Now keep app installed
4. When SMS comes from BT-BSZNMS-S or BX-OTNNOC-S, it auto parses

## Permissions needed:
- RECEIVE_SMS
- READ_SMS
